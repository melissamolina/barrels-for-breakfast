# Barrels for Breakfast

GitHub-ready landing page and demand-validation configurator for the next production batch.

## Deploy
Connect this repository to Netlify. No build command is required; publish directory is `.`.

## Form
The `next-batch` form uses Netlify Forms. Submissions include board information, intended use, material choice, contact details and notes. No payment is collected.

## Current preview
The bag preview is a lightweight interactive concept preview, not a production-accurate 3D model. Final material placement and construction may vary.
